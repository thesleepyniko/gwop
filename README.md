# great wall of phish (gwop)

![Athena Award Badge](https://img.shields.io/endpoint?url=https%3A%2F%2Faward.athena.hackclub.com%2Fapi%2Fbadge)

## What is this?

Hi there! This is a project called "gwop", or great wall of phish (great wall of china + phishing, get it?) It's intended as a link checker similar to virustotal. However, it's a lot less accurate and also pulls from less sources. (so please don't actually rely on it, theres a very high chance it will end up misleading you somehow :waa:) (also, its slow already for a scan so i don't want to throw a db and hashing into that mix)

## Why did you make this?

I'm interested in cybersec and it was very interesting to see how all these apis work and find all these services! I was planning to add GSB but that may be a later addition (way later, like resubmission kind of later) due to the fact that I don't want to mess with my very fragile deployment :pf:

## How did you make this?

It was made with ReactPy + tailwind for the frontend (a very silly python framework for the frontend), and fastapi on the backend. The whole stack is effectively python (i'm not even joking)
A lot of reading through documentation was required for this I must say, but overall i'm proud of it!

## What'd you struggle with and what'd you learn?

learning ReactPy was definitely...an experience to say the least. struggled with dark mode and eventually gave up and made it nontogglable. did learn reactpy though, and some strengths and weaknesses (its slow but it is super easy to integrate python into it!) i also learned some more web dev, and just kind of general interfacing with apis
